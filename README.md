# 운수 運數

> 내 사주로 여는 오늘의 운세 — 만세력 사주 풀이 · 오늘의 운세 · 궁합 · 행운 번호 모바일 웹앱

**Live** — https://unsu.vercel.app

![운수 미리보기](public/og.jpg)

## 소개

생년월일만 입력하면 만세력으로 사주 원국(여덟 글자)을 계산하고, 매일 바뀌는 오늘의 운세와 행운 번호, 두 사람의 궁합까지 보여 주는 모바일 웹앱입니다. 프레임워크 없이 **순수 HTML · CSS · JavaScript**로 퍼블리싱했고, 서버 없이도 가입·출석·포인트·광고·초대 흐름이 모두 동작하는 **작동하는 프로토타입**으로 만들었습니다.

## 주요 기능

| 영역 | 내용 |
|---|---|
| 만세력 | 입춘·12절기 기준 연·월주, 율리우스일 기반 일주, 시주(오서둔), 진태양시·1954~61 표준시·서머타임 보정, 음력·윤달 변환 |
| 사주 풀이 | 원국 표(십성·지장간·12운성), 오행 분포, 신강/신약, 용신·희신, 일간 해설, 신살·공망, 대운·세운·월운 |
| 오늘의 운세 | 오늘 일진 × 내 일간으로 재물·연애·직업 점수와 한 줄 결론, 행운의 팁(색·물건·음식·숫자) |
| 출석 · 엽전 | 출석 캘린더(출석한 날만 다시 보기), 연속 출석 보너스, 포인트(엽전) 적립·사용 내역 |
| 궁합 | 궁합 탭 안에서 두 사람을 바로 입력하거나 저장 목록에서 선택. 일간 합·상생·상극, 일지 합·충·원진, 오행 보완으로 점수 산출. 무료 요약 + 엽전/광고로 여는 상세 리포트 |
| 초대 링크 | "나랑 궁합 볼래?" 링크 → 받은 사람이 생년월일만 입력하면 두 사람의 궁합이 바로 열림 |
| 행운 번호 | 사주 원국 기반 평생 번호, 매일 바뀌는 오늘의 번호, 지난주 로또 1등 번호와 비교 |
| 별자리 | 12성좌 갤러리와 오늘의 별자리 운세 |

## UX 설계 포인트

- **가입 벽 없는 구조** — 로그인 여부가 아니라 "내 사주 등록 여부"로 화면을 나눴습니다. 게스트도 핵심 기능을 모두 쓰고, 로그인은 기록이 쌓였을 때(연속 출석 3일·포인트 60 이상 등)만 제안합니다.
- **4단계 온보딩** — 이름 → 생년월일(양/음력·윤달) → 태어난 시간 → 성별 → 확인. 입력 즉시 음양력 변환·띠·시진을 보여 줘 신뢰를 줍니다.
- **재방문 루프** — 오늘의 운세 → 자동 출석 → 엽전 → 상세 궁합 해제 → 공유/초대 → 신규 유입.
- **광고 배치 원칙** — 결론을 먼저 보여 준 뒤 네이티브 광고 1개, 보상형 광고는 끝까지 봐야 보상(목업).
- **예시 모드** — 입력 없이 7일째 출석 중인 사용자의 화면을 둘러볼 수 있고, 실제 데이터와 분리 저장됩니다.

## 폴더 구조

```
public/            배포 결과물 (Vercel이 그대로 서빙)
  index.html
  css/style.css
  js/lunar.js      음력 변환 라이브러리
  js/figures.js    성좌 일러스트 데이터 + SVG 렌더러
  js/core.js       만세력 엔진 + 해설 콘텐츠 + 오늘의 운세·궁합 로직
  js/app.js        화면·상태·흐름
  og.jpg, icons/, manifest.webmanifest
src/               원본 소스
api/lotto.js       최신 로또 당첨 결과 프록시 (서버리스, 30분 CDN 캐시)
scripts/build.js   src → public 빌드 (분리·압축)
scripts/og.js      미리보기 이미지·아이콘 생성
```

## 로컬 실행

```bash
npm install
npm run build:site   # src → public
npm run dev          # http://localhost:3000
```

## 알려진 한계

- 로그인·광고는 브라우저 안에서 동작하는 목업입니다 (실제 OAuth·광고 SDK 미연결).
- 로또 1등 번호는 `api/lotto.js`(Vercel 서버리스)가 동행복권 결과를 받아 30분 캐시로 자동 갱신합니다. 동행복권 응답이 막히면 `src/app.js`의 `LOTTO_LATEST` 정적 데이터로 표시됩니다.
- 절입 시각 ±10분 이내 출생은 월주가 달라질 수 있습니다 (저정밀 태양 황경 계산).
- 운세는 전통 명리 이론을 바탕으로 한 재미용 콘텐츠이며, 행운 번호는 당첨을 보장하지 않습니다.
