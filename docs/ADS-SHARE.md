# 광고(AdSense) · 결과 공유 링크

## 1. 분석 중 화면 광고
- 위치: 사주 입력 → `showGen()` 분석 화면 하단, 꿈풀이 로딩 카드 아래, 공유 링크로 연 사주 분석 화면.
- 분석 화면은 광고만 있지 않고 여덟 글자·오행 막대·진행률을 같이 보여 준다. 애드센스는 콘텐츠 없이 광고만 있는 화면(로딩·알림 화면)을 정책 위반으로 보기 때문.
- 광고가 있을 때 분석 화면은 3.8초(없으면 3.2초). 일부러 더 길게 붙잡지 않는다.

### 실제 광고 켜기
1. 커스텀 도메인 연결(woonijoa.*). 애드센스는 `*.vercel.app` 같은 남의 서브도메인으로는 사이트 등록이 안 된다.
2. 애드센스 사이트 등록 → 승인 후 광고 단위 2개 생성: 디스플레이(반응형) `feed`, 디스플레이(사각형) `loading`.
3. `src/app.js`의 `ADS`에 값 입력 후 `npm run build:site`:
   ```js
   var ADS = { client:'ca-pub-XXXXXXXXXXXXXXXX', slots:{ feed:'1111111111', loading:'2222222222' } };
   ```
4. `public/ads.txt` 추가: `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`
5. 비어 있으면 지금처럼 자리 표시만 나온다. 예시 모드·Claude 미리보기 안에서는 실제 광고를 부르지 않는다.
6. 구글 플레이 앱(웹뷰/TWA)으로 나가면 앱 안 광고는 AdMob 쪽으로 따로 붙여야 한다.

## 2. 결과 공유 링크 `?r=`
- 형식(base64url): `r1|타입|YYYYMMDD|추가값|사람1 7칸|사람2 7칸`
  - 타입: `s` 사주 · `d` 오늘 운세 · `n` 행운 번호 · `g` 궁합 · `z` 별자리(추가값 `별자리이름~생일ISO`) · `c` 분야별 운세(추가값 `money|love|career|job`)
  - 사람 7칸: 이름 · 성별 · 양/음력 · 윤달 · 생년월일 · 시분(모르면 빈칸) · 경도 보정
- 계산이 전부 seed 기반이라 입력값 + 날짜가 같으면 어느 기기·시간대에서 열어도 결과가 같다. 링크를 연 날이 아니라 **공유한 날짜** 기준으로 그린다(`VIEW_DATE`, 엔진 `calc({ now })`).
- 공유 시트에 "링크에 이름·생년월일·시간이 담긴다" 안내가 나온다.
- 깨진 링크는 토스트 후 홈으로.
