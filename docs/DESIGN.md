# 운픽 DESIGN.md — Liquid Glass (iOS 27 스타일)

애플 iOS 26에서 시작해 iOS 27에서 다듬어진 Liquid Glass 원칙을, 운픽의 밤하늘 톤을 파스텔(라벤더, 페리윙클, 라일락 핑크, 민트, 복숭아)로 낮춰 눈이 편하고 신비롭게 만든 뒤 웹에 옮긴 기준이다. 애플 공식 Figma 키트나 코드를 가져온 것은 아니고, 공개된 원칙(반투명 재질, 콘텐츠 우선, 떠 있는 컨트롤, 부드러운 스프링 모션, 접근성 설정 존중)을 CSS로 해석했다.

## 1. 원칙
1. **콘텐츠가 주인공**: 유리는 내비게이션과 컨트롤 층에만 쓴다(상단 바, 하단 탭바, 시트, 토스트, 칩). 본문 카드는 옅은 유리.
2. **떠 있는 컨트롤**: 하단 탭바는 화면 끝에 붙지 않고 캡슐로 떠 있다. 아래로 스크롤하면 작아지고 라벨이 숨는다.
3. **빛의 가장자리**: 유리 테두리는 선이 아니라 위쪽 하이라이트(흰색 20%)와 0.5px 헤어라인으로 표현한다.
4. **스프링 모션**: 눌림은 scale(.96), 이동은 `cubic-bezier(.32,1.28,.48,1)`.
5. **신뢰감**: 장식은 하늘(오로라)에만, UI는 차분하게. 결제·쿠폰 영역만 금색/분홍 강조.

## 2. 토큰 (src/app.src.html `:root`)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--canvas` | `#0d0b1e` | 배경(짙은 자두빛 밤) |
| `--glass-tint` | `rgba(48,42,84,.30)` | 카드 유리(라벤더 회색) |
| `--glass-tint-strong` | `rgba(24,28,62,.62)` | 진한 유리 |
| `--glass-blur` | `blur(26px) saturate(125%)` | backdrop-filter (채도를 과하게 올리지 않음) |
| `--glass-edge` | 위 하이라이트 + 0.5px 헤어라인 | 모든 유리 테두리 |
| `--glass-shadow` | `0 18px 44px rgba(3,4,16,.45)` | 떠 있는 그림자 |
| `--r-card` / `--r-sheet` | 24px / 32px | 곡률 |
| `--violet` | `#8a7cf0` | 주요 버튼(파스텔 바이올렛, 글자는 #1a1433) |
| 오로라 | 라벤더 170,160,240 · 라일락 226,178,226 · 민트 160,222,206 · 복숭아 244,200,184 | 배경 리본(농도 .09~.22) |
| 금색 | `#f3dca0`, `rgba(234,197,111,…)` | 엽전·결제 |
| 분홍 | `#ff9cc0` | 캐릭터·쿠폰 |

**글꼴**: `-apple-system, SF Pro, Pretendard Variable`. 아이폰에서는 SF Pro + Apple SD Gothic Neo, 안드로이드·PC에서는 Pretendard로 같은 인상. 제목은 700, 자간 -0.022em. 한자는 Noto Serif KR 유지.

## 3. 컴포넌트
- **상단 바**: 왼쪽 Woon 로고, 오른쪽 설정 버튼 하나. 설정 시트에 내 정보·우니·엽전·쿠폰함·글자 크기·앱 정보·약관. 게스트면 버튼에 금색 점. 맨 위에서는 투명, 스크롤하면 유리.
- **광고**: 네이티브 카드형, 한 화면에 1개, 결과를 다 본 뒤(오늘·사주 풀이·궁합·별자리·번호), 결제 화면에는 넣지 않음.
- **하단 탭바**: 흰색 4~10% 반투명 캡슐 유리(blur 14px) + 선택 탭 아래로 미끄러지는 렌즈(`.tab-lens`, `--ti`), 스페큘러 반사(`::after`). 140px 이상에서 아래로 스크롤하면 `body.tb-min`으로 축소.
- **카드**: `--glass-tint` + `--glass-edge` + `--glass-shadow`, 곡률 24px.
- **버튼**: Primary = 바이올렛 그라디언트 + 위 하이라이트. Soft = 흰색 8% 유리. 모두 캡슐.
- **시트**: 곡률 32px, 그래버 36×5, 넓은 화면에서는 아래가 떠 있는 카드형.
- **토스트 / 캐릭터 알림**: 캡슐 유리. 캐릭터 알림은 화면 위에서 내려온다(다이내믹 아일랜드 느낌).
- **접근성**: `prefers-reduced-transparency`이면 유리 대신 불투명 배경, `prefers-reduced-motion`이면 애니메이션 제거. 글자 크기 3단계(`--fs`)에서도 가로 넘침이 없어야 한다.

## 4. 키우는 캐릭터 '우니'
- **교감 게이지 0~100**: 콘텐츠마다 하루 한 번만 오름. 오늘의 운세 +10, 사주 풀이 +15, 궁합 +15, 별자리 +10, 행운 번호 추첨 +10, 신년운세 미리보기 +15 (하루 최대 75 → 2일에 한 번 가득 참).
- **표정 4단계**: 0~29 졸림, 30~69 미소, 70~99 신남, 100 사랑(하트, 볼터치, 깡총).
- **가득 차면**: 카드가 분홍빛으로 빛나고 "우니의 선물 받기" 버튼. 게스트는 로그인 시트로 연결(가입 전환).
- **선물**: 신년운세 1,000원 할인 쿠폰(7일, 한 장만 보유). 이미 있으면 엽전 100닢.
- **받으면**: 게이지 0, 한 단계 성장(새싹 별 → 아기 별 → 꼬마 별 → 반짝 별 → 보름달 별). 단계마다 별 더듬이 빛, 볼 별, 후광, 왕관이 붙는다.
- **벌 없음**: 접속하지 않아도 게이지는 줄지 않는다.
- 저장 키: `unsu_pet { g, lv, day, done, n }`, `unsu_coupons [{ id, t, name, amt, exp, used }]`.

## 꿈 해몽 번호 (2026-11-10)
- 진입: 오늘 탭 퀵버튼 '꿈 해몽 번호'(NEW), 번호 탭 프로모 카드, 우니 교감(dream +15)
- 입력 화면: 글자 수 10~500 · 경고문 5줄(엽전 즉시 소모·환불 불가 / 욕설·비방 금지 / 개인정보 금지·AI 전송 고지 / 재미용·만 19세 / 재풀이 시 재소모) · '위 내용을 확인했어요' 체크 후 버튼 활성

- 결과 화면: 분류 칩 · 제목 · 원문에 상징(번호) 표시 · 풀이 · 상징별 숫자 · 관련 숫자 · 꿈 번호 6개 · 광고 1개. 공유 버튼 없음
